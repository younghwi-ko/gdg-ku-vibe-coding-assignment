# 고영휘 — 소개 페이지

GDGoC KU 바이브 코딩 대체과제를 위해 만든 개인 소개 페이지입니다.

## 로컬에서 확인하기

별도의 설치나 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다.

## 배포

정적 HTML/CSS/JavaScript로 구성되어 Vercel에 저장소를 연결하면 바로 배포할 수 있습니다.

## 구성

- 고려대학교 화공생명공학과 1학년 자기소개
- 원자재 시황 모니터링 대시보드와 데이터 분석 경험
- 화학공학·생명공학, 데이터 분석, AI·웹 서비스 관심사
- 프로젝트 GitHub 링크
